📘 Ringkasan Materi

Kapasitor adalah komponen listrik yang menyimpan muatan dan energi listrik.

Kapasitas: C = Q / V
C = kapasitas (farad, F)
Q = muatan (coulomb, C)
V = beda potensial (volt, V)
Kapasitor keping sejajar: C = εA / d
Susunan paralel: Ctotal = C₁ + C₂ + ...
Susunan seri: 1/Ctotal = 1/C₁ + 1/C₂ + ...
Energi tersimpan: E = ½CV²

Catatan: 1 μF = 10⁻⁶ F dan 1 μC = 10⁻⁶ C.
